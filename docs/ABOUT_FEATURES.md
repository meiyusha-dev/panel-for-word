## 現行UI構成メモ

- ヘッダー: ロゴ + ナビ（機能詳細 / アドインについて）
- 左ペイン: タブバー + カードグリッド（3列、アイコン+ラベル）
- 右ペイン: 選択機能の詳細（タイトル・説明・画像）
- 機能ごとに `imgs` フィールドでスクリーンショット参照（未配置は onerror で非表示）
