かんたんツールボックス for Word

アドインの概要

かんたんツールボックス for Word は、Microsoft Word のタスクパネルに組み込まれるアドインです。 フォント・段落・数式・表など、日常的な書式設定操作をひとつのパネルから素早く実行できます。

  • フォントの一括変換・サイズ変更
  • 段落スタイル・行間・インデントの調整
  • 数式（分数・積分・行列・根号など）の挿入
  • 表の自動整形
  • よく使う機能をお気に入りに登録

動作環境

対応アプリMicrosoft Word
対応 OSWindows 10 / 11
対応プランMicrosoft 365（旧 Office 365）以降
必要 API バージョンWord JavaScript API 1.3 以上
インターネット接続必要

※ Mac 版 Word・Word Online・Word for iPad には対応していません。

基本的な使い方

1. アドインを開く

Word のリボンから ホーム タブ（または 挿入 タブ）内の「かんたんツールボックス」ボタンをクリックすると、画面右側にタスクパネルが表示されます。

2. 機能カードを選択する

パネル上部のカテゴリ（お気に入り・基本設定・文字組・枠・数式・定型文）をクリックして、目的の機能カードを選択します。

3. 操作を実行する

各カード内のボタンやスライダーを操作すると、Word ドキュメントに即座に反映されます。操作前にテキストや表を選択しておくと、選択範囲に対して書式が適用されます。

各機能の説明

お気に入り

よく使う機能カードを「お気に入り」タブに追加することで、機能を探す手間を省けます。カード右上の ★ アイコン・機能カード内の「お気に入りに登録」どちらかをクリックして登録してください。

基本設定

ページ設定確認

印刷前や他者からファイルを受け取った際に、用紙サイズ・余白・文字サイズが意図した設定になっているかをすばやく確認できます。

用紙サイズ

現在のドキュメントのページサイズをプルダウンから選択し変更します。

文字サイズ

対象テキストを選択後、文字サイズの数値を設定することができます。

ページ余白

上下左右の余白を設定することができます。

段組み

新聞・チラシ・会報誌など、紙面を複数列に分けて見やすくしたい場合に使用します。選択範囲に段組みを設定することができます。

文字数・行数

原稿用紙や社内規定フォーマットなど、1行の文字数・1ページの行数が決まっている文書を作成する際に使用します。1行に入る文字数・1ページに入る行数を設定できます。

スタイル管理

「文書をスキャンして書式状況を確認」を押下すると、書式状況の一覧が表示されます。
スタイルが当たっている／スタイルが上書きされている／未設定
の３つの項目が表示されており、意図しない書式が当たっているテキストを正規化することができます。

ステップ１
文書をスキャンし、スタイルを検索

ステップ２
対象を一覧から選択し、適用されているスタイルを確認。スタイルの除去ができます。

目次・フィールド更新

目次および文章内のフィールドを最新の状態に一括更新します。

変更履歴管理

「変更の記録を開始」ボタンを押下すると変更が記録され始めます。
「変更履歴の件数を確認」ボタンを押下すると、下部に変更履歴が一覧表示され、「全て承認する」ボタンから変更を確定することができます。

コメント管理

校閲・レビューが完了した後、残ったコメントをまとめて整理したいときに使用します。「コメント件数を確認」ボタンを押下すると件数が表示され、「全て解決済みにする」ボタンからコメントを一括で解決済みにすることができます。

ヘッダー・フッター

個別ページ設定
ヘッダーフッターの設定方法を選択し、入力することができます。
例：奇数ページ・中央・「MEIYUSHA」フッター入力

ページ番号設定
設定方法を選択し、ページ番号を挿入することができます。

図表番号

図や表を追加・削除・並び替えした後に番号がずれた場合、一括で正しい通し番号に更新します。相互参照も同時に更新されます。

改ページ制御

章の見出しや重要な段落を必ず新しいページから始めたい場合に使用します。選択した段落に改ページ設定を適用します。

脚注管理

文書内に散在する脚注を一覧で把握したいときに使用します。「件数を確認・一覧表示」を押下すると、下部に一覧が作成されます。

文字組

インデント

選択した段落の左・最初の行・右のインデントを設定できます。

行間

文書の読みやすさを調整したり、印刷時のページ収まりを整えたいときに使用します。選択行の行間を設定できます。

表

行数・列数を指定して表を作成します。

フォント取得・置換

他者から受け取ったファイルに意図しないフォントが混在しているときや、フォントを統一したいときに使用します。「取得」ボタンを押下するとドキュメントに使用されているフォント一覧が左窓に表示されます。
変換元・変換先フォントを入力し「フォント置換」ボタンから実行することで置換することができます。

ルビ

ルビ処理したい文字をカーソルで選択し「実行（自動ルビ）」ボタンを押してください。
文字単位ごとにルビを振ることができます。
また、任意で入力する場合は「ルビ入力（任意）」をご利用ください。
ルビが振られているテキストを選択して「ルビを解除」から解除することもできます。

枠

画像挿入

画像、図形ファイルなどを選択し、ドキュメント上に配置します。配置後は「レイアウトオプション」より、必要に応じて文字の折り返しを指定してください。

図形

テキスト枠または、長方形を文章中のカーソルに合わせて文字・行数、または数値で枠を作成します。配置後は「レイアウトオプション」より、必要に応じて文字の折り返しを指定してください。
枠の作成時、枠の種類をテキスト枠か長方形か選択してください。
「サイズパレット」より、サイズ変更も可能です。

数式

各種数式カード内のアイコンから目的の数式を入力することができます。

定型文

定型文入力

あらかじめスロットに入力したテキストを定型文として入力することができます。
スロットを選択した状態で「文章よりコピー登録」を選択すると、ドキュメント内のテキストを定型文として登録することができます。

記号スロット

あらかじめ4種の括弧付き数字や丸付き数字などを登録しておき、「実行」ボタンを押すと連番入力することができます。
例：⑴→⑵→⑶→⑷・・・
